# ECDICT attribution

`starter-glosses.json` is a transformed subset of the ECDICT English-Chinese
dictionary, filtered to the level 2-4 words already listed by ReadWise and
reduced to one short Chinese gloss per word.

`word-dictionary.json` retains phonetics and full Chinese translations for
ReadWise's level words, starter glosses and English lemma headwords. It is
an offline subset, not a complete dictionary; examples are not included.
Generated from the same source revision by `scripts/generate_word_dictionary.py`.

`reader-vocabulary.json` contains short Chinese glosses and local reading
frequency bands for the checked-in dictionary headwords. These bands approximate
reading difficulty; they are **not official CEFR vocabulary labels**. Generated
from the same ECDICT CSV snapshot (BNC/COCA rank columns) with:

```bash
python scripts/generate_reader_vocabulary.py ECDICT_CSV core/src/vocab/data/reader-vocabulary.json
```

The six rank boundaries are 1000, 2500, 5000, 10000, 20000 and 50000;
unknown/rarer entries use band 7. A missing rank falls back to the old local
school/exam word tier plus one, when available. It does not alter the old
`word-levels.json` or stored vocabulary review levels.
