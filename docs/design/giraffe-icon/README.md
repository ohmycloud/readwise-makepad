## 设计简报与假设

- 产品：ReadWise，本地 EPUB 阅读、词汇积累与辅助学习应用。
- 气质假设：亲切、安静、有耐心；可爱但不过度儿童化。
- 参考：`/Users/ohmycloud/blogs/ohmycloud/_includes/cop.svg`。
- 保留正面长脸、横向耳朵、短角、点状眼睛和宽口鼻部；在 256 单位画布上重绘路径。
- 大耳朵略有翻开书页的形态，但不额外添加书本、字母或 AI 元素，避免小尺寸拥挤。
- 使用圆角底板预览；正式资源的圆角和安全区须按各平台规范处理。
- 选择方向后，再制作正式图标、小尺寸简化版、单色与反白版本等。

## 检查记录与限制

- 已用 rsvg-convert 渲染并查看总览，用 Chrome 渲染并查看网页预览；比较 48/32/16px 和 64/32/24/16px 尺寸。
- 根据预览修正角部接缝：填色连通圆角、角柄与头顶，避免深色方案出现悬浮圆点。早期 F 版本保存在 `iterations/`。
- 六个图标 SVG 均为纯矢量，无字体依赖、滤镜或位图；结构审计未报告 FAIL。仍保留缩放描边，正式母版需扩展为轮廓。
- 16px 仅保留基本轮廓，角柄、鼻孔等细节较弱，不能视为最终 favicon 验收；选定后另作小尺寸版本。
- 自动检查页中的“整图单色”会连同底板一起变色，不代表有效的单色品牌稿。本轮未完成独立单色、反白、圆形裁切、真机桌面或印刷验收。
- 演示图与网页的文字使用系统字体，仅用于排版，不是正式字标。
- 参考 SVG 带有 SVG Repo 注释，但没有明确许可证。新路径为本轮重绘，仍不构成参考素材授权或商标无冲突保证，发布前需核查授权与商标近似性。

## 重建

```bash
python3 docs/design/giraffe-icon/generate.py
```

需要 `rsvg-convert`。该脚本重建六个 SVG、总览 SVG/PNG 和网页，不修改应用资源。`tests.html` 与 `audit.txt` 由本机 `logo-design` 技能脚本另外生成。
