# ReadWise Web（Topcoat）

## 定位与当前范围

Web 是新增的 **Topcoat 服务端渲染客户端**，不是把 Makepad 编译为 WASM，也不替换现有桌面/手机应用。沿用 `readwise-core` 的 SQLite、EPUB/PDF 解析、内置词库、词形还原、已认识词和词汇本。

第一阶段已经实现：

- 真实数据库书架；浏览器逐本上传 EPUB/PDF，支持批量逐本反馈。
- 书架列表／网格切换、未读／在读／读完与进度百分比，以及分享、欲读清单、藏书标签、标记读完、改名和二次确认删除，复用原生核心接口。
- 章节、目录、书内章节链接、受限图片路由；PDF 使用既有文本快照与迁移链路，不是原版面 PDF 查看器。
- 浏览器原生 ruby 注音、词卡、标为已认识/恢复注音、加入/移出词汇本。
- PDF 文本层公式按原字形／基线／横线坐标恢复，通过嵌入式 Typst 输出矢量图，支持可确认的分式、根号及行内／块级上下标；不改原文本快照或源锚点。
- 代码块离线语法高亮，明暗背景切换不替换代码节点；暖棕色选文工具栏沿用桌面图标和操作布局。
- 选文的复制/引文、四种持久化高亮、笔记撰写、词汇入库、书内文本搜索；翻译/事实核查为外部链接，发音使用浏览器语音能力。
- 可配置的 OpenAI 兼容选文问答、解释、释义；不是空按钮，也不是桌面流式多轮聊天的完整移植。
- aA 的「主题／文本／注音」三页签与全局设置共用偏好：界面语言、英文水平、明暗主题、8 种背景、字体/字号/行距/宽度/对齐/缩进、分栏/翻页、标记色和注音；保留草稿预览、分区重置、明确保存与取消。
- 注音四项自定义色、内嵌饱和度／明度／色相取色器、Hex 输入和推荐色；最多 32 套 Favorite 配色，支持套用、取消收藏和逐套删除。草稿与阅读设置一起明确保存。
- 只读载入本机桌面阅读设置为草稿；应用后写入 Web 设置，不修改桌面数据库。
- 连续滚动、CSS 多栏分页、滑动/轻量卷页过渡、上一章/下一章、文本锚点保存与重启恢复。
- 词汇页及来自当前数据库的藏书、在读、词汇、笔记统计。
- 响应式桌面/手机窄视口；手机导航为等宽「阅读、书架、词汇、我」，统计归入个人设置页。

**尚未实现，不视为完整原生端移植：** 物理跟手卷纸/原生分页引擎、全书精确页码、已有笔记编辑/管理、书签、阅读计时、AI 流式多轮会话/历史/skills/本地模型进程管理、跨端书库自动同步、用户认证、多用户隔离、自动双向同步、PWA 与离线章节缓存。Web 高亮使用独立表，不与原生 TextFlow 高亮坐标混用。

当前版本只允许回环地址，适合本机单用户使用和开发验收；不应通过反向代理、隧道或修改监听限制直接暴露到公网。

## 环境与启动

- Rust **1.99+**，项目固定 `topcoat = "=0.11.0"`。
- Topcoat CLI **0.11.0**（与资源协议匹配）。

```bash
cargo install topcoat-cli --version 0.11.0 --locked
scripts/run_web.sh
```

打开 `http://127.0.0.1:3000`。

脚本先执行 `topcoat asset bundle -p readwise-web`，生成与可执行文件匹配的 CSS、浏览器 JS 和 Topcoat runtime，再启动服务。前端没有 React、Node 或 WASM 构建步骤；Node 仅用于可选的浏览器回归测试。

也可以手动执行：

```bash
topcoat asset bundle -p readwise-web
cargo run --locked -p readwise-web
```

更改 Rust/CSS/浏览器脚本后重新打包资源；仅运行 `cargo run` 不会自动更新资源目录。缺少资源时会提示打包命令。

开发热更新可使用 `topcoat dev -p readwise-web`。本应用自行管理监听地址，使用下面的 `READWISE_WEB_BIND` 配置，而不是 Topcoat `HOST` / `PORT`。

### 数据目录与监听

默认使用系统 ReadWise 数据目录下的 **`web/` 子目录**，与 Makepad 的数据库、书籍和设置隔离。例如 macOS：

```text
~/Library/Application Support/ReadWise/web/
├── database/app.db
├── books/<书籍 UUID>/
├── uploads/                 # 私有接收临时文件
└── web-server.lock          # 防止两个 Web 服务同时使用该目录
```

可显式指定独立目录与端口：

```bash
READWISE_WEB_DATA_DIR="$HOME/ReadWise-Web-Data" \
READWISE_WEB_BIND="127.0.0.1:3100" \
  scripts/run_web.sh
```

支持 IPv4 / IPv6 回环 IP，拒绝 `0.0.0.0` 和局域网地址。一次只有一个 Web 服务能持有数据目录锁；监听端口为 `0` 时由系统分配并打印实际网址。

**不要直接指向正在使用的原生数据目录。** Web 位置编码为 `web:v1:章节:块:UTF-8字节偏移`，不是 Makepad 的 `v3` TextFlow 坐标；目前没有跨端同步或位置迁移。要研究既有书库，请先备份，并在停止原生客户端后使用完整数据目录的副本。

### 与桌面设置对齐

在「我 → 阅读设置」点击 **载入桌面阅读设置**，仅只读读取当前电脑桌面数据目录的 `database/app.db`；预览草稿后点击 **应用并保存**，写入独立的 Web 数据库。离开设置页或关闭 aA 而未应用，不会保存草稿。桌面数据库不存在时提示错误，不创建它，不做桌面迁移，不读取 AI 密钥，也不同步书籍、词汇、笔记和阅读位置。

可通过 `READWISE_WEB_DESKTOP_DATA_DIR=/path/to/desktop-data` 指定只读快照来源，值为数据根目录，不是 SQLite 文件。默认来源为 `readwise_core::paths::app_data_dir()`。这不是自动监视或双向同步；桌面再次修改后需要重新载入。原生正文字号与浏览器 CSS 像素按 ×2 换算，注音按 ×1.4 换算，界面显示仍采用原生字号数值；颜色槽位不重映射。字体采用本机安装字体及同类后备，不捆绑商业字体。

## 实现边界

### Topcoat 与浏览器脚本

注音外观参考 `/Users/ohmycloud/Downloads/annotation-topcoat` 的实现：四个 Topcoat `signal` 保存 CSS 颜色，`:style` 绑定即时更新浏览器中的预览，不为色板点击请求服务端。色板顺序与原生端一致：背景为「无、奶黄 #FFE9A8、薄荷 #CFE8D5、雾蓝 #D3E6F7」。

`web/src/browser.js` 负责浏览器能力及交互协调，`appearance.js`、`selection.js`、`pager.js` 分别处理设置草稿、选文操作与同 DOM 分页；不另建 UI 框架。直接打开设置页时等待 Topcoat 的色板信号完成投影，避免动态模块先于 hydration 读到空选中项。

- aA 预览只影响弹窗草稿，取消不写数据库；旋转仅改变 CSS 布局，不重建信号或丢失草稿。
- 保存颜色直接更新正文 CSS 变量，不重载章节。
- 字体、字号、行距、宽度、分栏等实际排版变化，应用后按文本锚点补偿位置。
- 全局设置与 aA 写入相同偏好；API 部分更新合并已有值，不因旧客户端只提交注音字段就重置主题/文本设置。
- 英语水平变化需要重新选择注音词集合，因此保存位置后重载当前章节。

### Fluent 界面本地化

Topcoat 固定为 0.11.0，最低 Rust 1.99，CLI 必须同为 0.11.0。每个页面请求在 layer 中读取一次 `Preferences`，将不可变快照和已保存语言的 `Locale` 放入请求上下文。页面外壳、设置控件及正文注音使用同一快照；API 写入后下一请求重新读取，不使用跨请求设置缓存。浏览器语言不会覆盖用户已保存的选择。

`web/src/l10n/{zh-CN,en}.ftl` 是界面译文来源，`i18n.rs` 用 Topcoat `messages!` / `t!` 在服务端解析。英文标题、按钮、ARIA、placeholder 和数量文案不依赖 JavaScript 才能显示。`i18n.rs` 保留中文调用别名以兼容既有浏览器动作；新增文案需同时增加 Fluent key 和别名映射。运行 `topcoat l10n check -p readwise-web` 检查两种语言的 key、变量和引用。

两份已解析的固定界面 catalog 随页面以转义 JSON 提供给 `i18n.js`；它只更新明确标记的 `data-i18n*` 界面节点，不遍历任意文本、不猜测用户内容，也不在浏览器执行 Fluent 或求值表达式。四种简单数量文案由 Fluent 以命名占位参数投影为文本模板，再做纯文本替换；复杂复数／语法分支应在服务端用真实参数解析，不能直接套用该模板路径。译文和调用别名都按文本转义，不作为 HTML 注入。

语言选择沿用草稿／应用／取消语义；已保存语言的跨标签页通知原地更新界面，不重载或替换阅读正文。书名、作者、用户标签、书籍原文、注音、笔记、选文及 AI 回答不参与界面翻译。核心或外部服务返回的原始错误仍可能保持其原始语言。未引入 runtime 客户端导航、shard、Topcoat UI 或 Popover；原生 `<dialog>` 和内嵌取色卡片保持不变。AI 密钥仍在保存成功后显式清空输入框，不依赖重渲染覆盖输入值。

新增隔离回归 `node web/tests/l10n.cjs` 覆盖禁用 JS 的双语 SSR、持久化语言优先、文案完整性、草稿丢弃／应用、跨标签页正文节点与几何不变，以及与界面文案同名的书名／标签／原文不被误翻译。

### 自定义注音配色与 Favorite

全局阅读设置和 aA「注音」共用同一套控件。在「词背景」预设行下方提供四个初始透明的入口：**注音颜色、注音背景、词字色、词背景**。点击任意入口，在这一行正下方展开唯一的内嵌取色卡片，切换入口复用卡片；选择颜色后入口显示已选色。原有预设槽位仍是 0–3，不增加或重排原生槽位；选择某行预设会清除该项自定义覆盖，「恢复预设」回到该行当前预设。背景的「无」及词字色「默认」继续通过原预设提供。

卡片包含可实际拖动的饱和度／明度平面、色相滑块、Hex 输入及推荐色；平面也支持方向键（Shift 加大步长）。Hex 支持 `#RGB` 和 `#RRGGBB`，前者展开保存为六位；不接受 CSS 函数、URL、任意颜色名或样式片段。无效／未完成输入只提示，不覆盖最后有效颜色，且阻止保存。预览实时变色，无需请求服务端；只有点击「应用并保存」才改变正文配色。应用颜色仅修改 CSS 绘制变量，不重新加载章节、替换 ruby 或触发几何分页。

「收藏这套配色」把四项**实际显示色**组成一套 Favorite，包含透明背景／继承字色的状态，不包含字号、主题或其他阅读设置。同一套颜色忽略 Hex 大小写去重；最多保存 32 套。每套有独立的注音／Aa 预览、四个颜色指示、套用和删除按钮；当前组合有选中边框，主按钮可取消收藏。收藏、删除、调色和套用均为设置草稿，aA 关闭／取消全部放弃；旋转不丢草稿，保存失败保留草稿。重置注音恢复默认四项颜色，但不删除 Favorite。载入桌面设置不会删除现有收藏。

Web 用 `Preferences.custom_colors` 的四个可空 Hex 和 `favorites` 的四项有效色保存扩展；数据放在同一 Web SQLite 的 `app_settings['web.annotation_colours.v1']`，不写入原生槽位或桌面快照。核心仅新增可选扩展读写入口，扩展 JSON 与全部原生阅读设置在**同一个事务**中提交，扩展写入失败则整组回滚；原生旧调用不受影响。部分设置更新和高亮笔色接口保留扩展。服务端同样校验颜色格式、收藏上限、字段结构和重复组合，不信任浏览器输入。

### 书架管理

书架卡片底部显示真实 `book_status` 状态及 `progress_current / progress_total` 百分比，与桌面一致；当前 Web 保存的是章节进度，不冒充全书精确页码。列表／网格偏好保存在浏览器本地，刷新后保留。浏览器返回若命中 BFCache，只刷新书架以更新最新阅读进度，不重载阅读正文。

每本书的「⋯」打开独立顶层对话框，提供：分享（复制书名和作者，与桌面一致）、加入／移出欲读清单、添加到藏书（编辑标签）、标记为已读完、重新命名、删除。`POST /api/books/{UUID}` 使用原生 `Db` 接口，保留原生书名／标签校验和欲读状态独立性；改名、标签和欲读操作不改阅读锚点。API 不返回私有绝对路径。

删除必须再次确认；成功后才移除卡片并更新数量，最后一本删除后恢复空状态。沿用核心删除语义：删除应用内书籍副本、进度与书内高亮（包括 Web 高亮），清理章节缓存；`notes` 表的独立摘录保留并解除书籍关联，确认文案明确说明这一点。应用外的用户原始文件不删除。错误显示在当前弹窗，保留输入和书籍，支持重试；操作进行中禁用按钮防重复提交。

菜单、编辑和确认对话框按视口与四边安全区限制尺寸，矮横屏内部滚动，旋转不丢草稿。书籍链接与更多按钮共同使用整段 pointer 手势判定，拖动返回起点、长按、多指或点停惯性均不当作轻点；仍让浏览器收到松手清理事件，键盘激活保持可用。

### 阅读连续性

服务端始终为当前等级的所有注音候选词保留相同 ruby 槽位，已认识状态只投影到 `data-known`。前端通过 **`visibility: hidden`** 隐藏 `rt`，不删除 ruby/rt、不清空释义文本、不使用 `display:none`，保留词宽、行高和断行。

标为已认识时：立即隐藏注音并关闭词卡，后台保存；失败时只恢复状态，不替换章节 DOM。翻章、刷新、浏览器返回及跨标签页通知都会重新同步已认识状态。服务端章节缓存只存稳定的安全正文，不因已认识集合变化而清空。

阅读位置保存章节、原始分块编号和去除 `rt` 后的文本 UTF-8 偏移，不保存滚动像素或屏幕页码。正常导航前尽量提交最新锚点；网络不可用时提示保存失败，不把未保存状态报告为成功。

### 分页和布局

分页使用浏览器 CSS 多栏并平移同一个 article，不复制正文或为翻页重建 ruby；页码仅是当前章节/视口的页数，位置始终保存源文本锚点。窄屏回退单列但保留双列偏好；上下滚动模式使用单列。横竖屏重排恢复同一源位置。分页正文和两行导航分配在实际视口内，代码/表格过高时使用内部滚动，不把尾部裁掉。

支持按钮、左右方向键与横向触摸滑动；选文、对话框或输入控件活动时不截取阅读翻页。轻量卷页是 CSS 视觉过渡，不是桌面 GPU 纸张模拟；遵守浏览器减少动态效果偏好。

### PDF 公式与 Typst

Web 与桌面共用 `readwise-math`（`math/src/`）；`web/src/math.rs` 只重导出共享接口。引擎在读取 PDF 章节时，另外提取该页的原始字形、字号、基线及水平矢量线；用数学字体／符号和几何分组寻找公式候选，要求字形集合能唯一对应既有安全正文中的连续源范围，再交给内嵌 **Typst 0.15.1** 排字并输出 SVG 字形轮廓。分式横线沿用原坐标；PDF 符号字体的根号基线常位于顶端，根号笔画按原覆盖横线及其下字形恢复，不能直接用 Unicode 根号的字体基线。若旧快照将下标或运算符排到同段的其他位置，`math/src/scattered.rs` 要求整个段落能唯一匹配原 PDF span 字符流，再用字形坐标、基符号／脚标层级及分式横线恢复关联。完整公式在主锚点显示，离散的旧源字符在原位置保留零宽代理；既不重排 DOM 源文字，也不写回或迁移快照。跨块、重复段落或不完整映射仍回退原文。普通正文中的行内公式不能因恰好占一个 PDF 行就把整段当作行间公式。CMEX 标准字体的 `P`／`X` 槽按求和字形绘制，并修正其基线；普通字体中的 P／X 不变，旧源字符本身也不改。

这是**原 PDF 几何的显示投影**，不是从扁平文字猜出语义化 Typst／LaTeX，也不是通用数学 OCR。缺失文字层、旋转字形、无匹配、范围歧义、复杂表格／链接／代码及超预算内容保持原安全文本；并未新增 EPUB MathML、LaTeX 分隔符解析或语义公式导出。

SVG 随服务端页面一次生成，不等待浏览器异步替换正文。尺寸随正文 em 缩放、颜色继承阅读主题；窄屏公式在自身横向滚动，支持聚焦后方向键，数学区域滑动不触发翻页。SVG 只含可信编译器生成的绘图，字形 ID 按页与公式加前缀。另有透明定位选择层，**按原始提取顺序逐字保留 UTF-8 文本及空白**，复制仍是原文本，不伪称 LaTeX；锚点、高亮和摘录排除 SVG，不变更块号或字节坐标。公式不被词汇注音拆开，已认识词、配色变化不清理几何投影缓存。离散源的复制仍遵循所选主锚点的原文本，不声称恢复了语义化公式文本。

行内公式的 em 和基线参照原 PDF 中几何邻近的普通正文，不能把分式的小号分子／分母放大到正文字号，或把分母基线当正文基线。SVG 的行内画布使用 Typst 最终字形与笔画（含线宽）的实际边界，去除空字体框留白并保留少量抗锯齿余量；透明选文层与画布同步移动，行间公式保留独立排版。不通过全局改行距、零高覆盖或固定限高来隐藏问题，不裁掉分子、分母、根号和脚标。没有邻近正文证据时保留公式自身的字号／基线参考。

公式作为**完整的视觉选区单元**：原生拖选进入公式时选取整项，选文边界也按源范围扩展；不与正文混选的公式及行间公式按 `.math-canvas` 完整矩形绘制，不用透明文字的字体框推断分子、根号和上下限；**整段混选时，行内公式加入所属 flow／column 的正文行带**，以实际正文基线归行，统一同一行的上下边界并覆盖全部墨迹，邻行共享同一中间边界，不能只在公式位置补一个高低不同的矩形或在行间留下白缝。旧高亮若命中离散代理，仍映射到所属公式；恢复该源锚点时也定位到实际公式。绘制只更新既有背景层，不替换节点、不染色字形；横向滚动按公式实际浮点边界裁切，不能使用取整的 `clientHeight`／`clientWidth` 截掉小数 DPR 下的一条底边。普通段落、行内代码及双栏中缝继续沿用原绘制约束。

编译只接受应用生成的定位指令；PDF 字符经过字符串引号转义，不作为 Typst 程序执行。闭合 World 只提供主源码及内置字体，拒绝任意文件／包，禁用时钟，不调用外部 CLI、系统字体或在线服务。每公式限制 512 字形／64 笔画／1 MiB SVG，每页限制 64 个公式、2048 个绘制字形／8 MiB 输出（离散源代理另限 128 个范围）；页缓存最多 6 页且总计 8 MiB，删除图书同步释放。编译沿用后台工作任务并定期淘汰 Typst 计算缓存。这些预算不构成任意恶意 PDF 的进程级沙箱。

桌面由 `app/src/reader_math.rs` 注册 Makepad 原生 HTML 组件，将同一份 Typst SVG 交给 `DrawSvg` GPU 绘制，不需要浏览器或 Web 服务。原生网格按最终逻辑尺寸乘实际 DPI 细分，GPU 只做设备像素到逻辑像素的换算，不能把 PDF 点单位的抗锯齿边缘一起放大成粗黑字；字号／DPI 变化时重建绘图网格，不改 Typst viewBox、正文排版或源坐标。TextFlow 保留原始源字符及离散代理的选择缓冲，命中按完整公式处理；混排高亮先按正文基线归行并合并重复代理，再交给原生连续行带绘制。初次页在现有打开书籍后台线程编译，后续页异步准备；目的页完成前保留当前正文与历史，不先显示扁平文字再替换。当前页投影在缓存淘汰中受保护，过期书籍任务不应用；翻页可取消旧目的页，离开阅读不会因任务完成强制跳回。单书最多两项待编译工作，常规页缓存六页／8 MiB；若当前页与刚完成的目的页本身就超出合计预算，暂保留这两页（各自仍受单页上限约束），不靠驱逐当前页清理界面。仅 PDF 启用此显示投影。

字体来自 `typst-assets`，原生资源同样保留 [`app/resources/third-party/typst-assets/`](../app/resources/third-party/typst-assets/) 的许可证和声明；桌面打包脚本将其放入发行包，移动资源沿 Makepad 资源打包流程携带，不能只分发裸二进制而遗漏声明。再分发 Web 可执行文件时须附带 [`web/third-party/typst-assets/LICENSE`](../web/third-party/typst-assets/LICENSE) 和 [`NOTICE`](../web/third-party/typst-assets/NOTICE)，不得将其一概声明为同一种字体许可证。

### 代码高亮与选文

代码块在 HTML 白名单清理后使用 Syntect 的内置语法和主题渲染。只保留 `pre/code` 的 `language-*` / `lang-*` 语言提示，无提示时识别常见 Rust、Python、JavaScript、JSON 模式；无法识别的内容保持纯文本。关键字、字符串、注释着色不依赖网络。源码的实体、缩进及首尾换行保留，不为代码添加注音；超过 128 KiB 或单行超过 8192 字节时保留安全原文，避免无限制解析。发布者提供的 style 仍被剥除，只有内置高亮器可生成受信任的 token 样式。token 在同一节点声明浅色/深色配色，现代浏览器通过 `light-dark()` 切换，旧浏览器退回可读的浅色代码卡片。

选文工具栏由 `Selection/Range` 驱动，鼠标拖动松手后出现，也响应系统选区变化；是 fixed 覆盖层，不改正文视口或重建章节。位置按实际可视视口与四边安全区钳制，滚动、旋转时重新定位；Escape、取消或清空选区可关闭。复制和摘录只读取正文文本节点，排除 `rt/rp`，保留代码缩进及跨段边界。保存失败保留选区并提示，不报告成功。

四个圆形高亮色块是直接操作：点击后以该颜色高亮并保存当前选文，成功后关闭选文工具栏，同时记住默认高亮色，不需要再点左侧高亮笔。左侧高亮笔保留“添加/移除”切换；色块则始终应用颜色，重复点击同色不会删除或堆叠重复范围。`POST /api/highlights/apply` 在一个事务内替换与选区重叠的颜色，保留未选中的旧高亮前后片段，返回当前章节的完整高亮快照；不改原生坐标或数据库结构。颜色偏好与高亮是两次请求，若高亮写入失败，默认色可能已经更新，但原高亮和选区保留并明确提示失败。请求进行中统一禁用高亮相关按钮；慢成功仅关闭原来的选区，不清空后来新选的文本，跨标签通知延后刷新。

「保存摘录」及「添加笔记」通过受同源保护的 `/api/excerpts` 写入核心 `notes` 表，限制选文 24000 UTF-8 字节、附加想法 12000 字节；服务端验证书籍和章节并提供来源，阅读页「摘录」可查看，重启后保留。笔记对话框支持编辑未保存草稿，尚不提供对已存笔记的修改/删除。

高亮仅改变背景绘制，不拆分或包裹正文节点；支持跨块范围、四种颜色及重叠高亮移除。`highlight.mjs` 在文字下方绘制统一、无命中的连续 SVG 背景，不再拼接原生字体背景与“挖洞补色”：`Range.getClientRects()` 并不保证等于字体背景的实际光栅范围，按 CSS/设备像素取整仍可能产生细缝或重复着色。按真实行片段、code/注音词的 border/padding box、流容器及列生成范围；同色合并一次，异色按固定顺序叠放。对于会遮住底层的 code/pre/词背景，完全覆盖时用一次合成的 CSS 背景色，部分覆盖时将原底色和高亮合成为一个 CSS 背景 SVG，匹配换行 inline 背景的连续切片坐标；所有字形、颜色及抗锯齿仍由浏览器原样绘制。选文保留原生 Range/复制/触摸手柄，Highlight API 保留范围注册但背景透明；仍要求支持该 API 的现代浏览器。只选代码前缀或后缀时不扩展未选的逻辑边缘，不改变行距、padding 或源坐标。段间距、双栏中缝和阅读/代码滚动区之外不补画。背景层绝对定位在正文的滚动容器中，连续滚动模式预先保留屏外完整行带，和正文由浏览器一起滚动，不依赖固定屏幕覆盖层逐帧追赶；暂停 JavaScript 绘制帧时仍须对齐。内部公式／代码滚动、换页、旋转和字体变化才按帧更新几何。设置/已认识状态变化时重新读取原底色，取消/移除后恢复；自身背景样式更新不形成持续重绘循环。`web_highlights` 表保存按无 rt/rp 正文计算的 UTF-8 坐标，服务端拒绝越界、跨字符和空范围；**不写入原生 `book_notes` 的 TextFlow 坐标**。不支持 Highlight API 的浏览器会提示升级，不用改变正文 DOM 的降级方案冒充支持。

### AI 和外部服务

在全局 AI 设置中配置 OpenAI 兼容接口、模型及可选 API Key。问 AI、解释、释义与更多菜单的 AI 提问均真实发请求；仅在用户提交时发送选文、书名、章节和问题，不自动上传整本书。Key 使用核心设置存储（SQLite 中未加密），不会写入 HTML 或 GET 响应，留空保留旧值，勾选清除才删除。不会从桌面快照自动复制 Key。

请求为非流式单次问答，有限并发、90 秒总超时、2 MiB 响应上限、禁止重定向；错误不回显密钥或上游原始响应。关闭对话框中止浏览器等待，不保证服务商已停止计费/生成。回答按纯文本显示，不执行模型 HTML。浏览器翻译/事实核查会将选文送往外部网站；语音可用性取决于浏览器/系统。书内「相关内容」是本地文本匹配，不是语义向量检索。

### 后台与存储

既有 `Db` 拥有自己的 Tokio runtime，因此在有界 `spawn_blocking` 工作任务中调用，使用互斥访问，不在 Topcoat 异步处理器里直接嵌套 `block_on`。书籍解析和复制同样在工作线程完成。最多四个已获取工作许可的任务，章节缓存最多三本、安全正文及坐标验证文本合计最多 32 MiB；超出预算的单本不缓存。

上传按 multipart chunk 写入磁盘，不先将整本文件读入内存。每本最大 200 MiB；浏览器每请求一本并顺序处理批量。只有核心解析和数据库事务成功后才返回成功。

上传保存在私有 `TempDir` 中，使用去除路径、限制长度的原文件名，保留无标题 PDF 的文件名回退；目录在成功、失败、请求中断后释放。下次启动取得独占数据目录锁后，只清理 `uploads/` 中自身前缀的遗留接收目录/文件。不删除用户选择的原始书籍。EPUB 预检限制条目数及声明解压大小，降低压缩炸弹风险；不是针对任意恶意文档的完整沙箱。

### 浏览器安全

- Makepad 的 HTML 清理器不是浏览器安全边界；Web 投影另用 Ammonia 白名单清理脚本、事件、表单、危险链接和样式。
- 释义作为文本转义；只对清理并注入后的可信正文使用 Topcoat `Unescaped`。
- 图片 URL 不暴露绝对路径，只通过书籍 UUID 和已登记图片索引访问；规范化路径必须位于该书私有目录，不提供任意文件下载。只允许 PNG/JPEG/GIF/WebP，不直接提供 SVG。
- 内容锚点加前缀，避免与应用控件 ID 冲突。
- 校验 Host，保留 Topcoat 默认 OriginPolicy；修改 API 还要求自定义同源请求头，不开放 CORS。
- 设置、词形及位置输入检查范围，修改不使用 GET；响应设置 `nosniff`、禁止嵌入和不缓存私人页面。

这些措施不等于认证、多用户授权或公网生产环境安全审计。
