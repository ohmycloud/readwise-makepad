# PDF 文本阅读

阅读器使用 [pdf_oxide](https://github.com/yfedoseev/pdf_oxide) **0.3.78** 提取 PDF 的文本与语义结构，转为与 EPUB 相同的正文 HTML。普通正文使用文本重排；书库封面及保守确认的矢量图区域使用 hayro **0.7.1** 离线渲染，后者不包含标题、图注或正文，只作显示投影，不改文本快照。不依赖 PDFium、浏览器或系统 PDF 框架；hayro 声明的最低 Rust 版本为 1.92。

## 导入与阅读

- 「导入书籍」的本机选择器支持 `.epub` 和 `.pdf`，包括大写扩展名和批量选择；桌面也可拖放，或放入 `ReadWise/import` 后启动应用。
- 局域网传书网页同时接受 EPUB / PDF，每本最大 200 MB。PDF 的文本提取及入库均成功后才返回成功，失败会清理应用的临时副本；原有接收会话、停止及后台接收逻辑保持不变。
- 读取 PDF 标题、作者与语言；缺少标题时使用文件名。新导入的 PDF 在后台生成首页 PNG 封面（最长边 600px，尊重裁剪及旋转，白色底色）。启动时先显示书库，再逐本后台补齐旧 PDF 缺失的封面；已有封面保留，补齐时不重置列表位置、筛选或阅读数据。封面单独生成，不写回原 PDF、不重建正文快照；遇到不支持的首页或超过 200 MiB 的文件时保留文字占位，不阻止正常的文本导入。
- **文本可以重排、选择、复制、搜索、高亮、加笔记、点击查词和显示注音**，与 EPUB 共用现有实现。字号、字体、边距、单／双栏及翻页设置也使用相同的阅读流程。
- 「标为已认识」只隐藏注音，保留 ruby 槽位、当前正文、分页和阅读位置；后台页码重算不会清空当前页几何缓存。
- 导航目录优先读取 PDF 自带的大纲，保留最多三级显示层级；没有可用大纲时提供逐原始页目录。页面上印刷的目录独立处理：在正文重排前按逐字坐标恢复原始行、混合字号章节标题、页码及可确认的双栏顺序，避免条目粘成正文段落；这些行仍可按当前视口换行。普通正文不强制逐原始行断开。
- 链接边界按原 PDF 的链接矩形／QuadPoints 和逐字几何恢复，不再将与矩形略有重叠的整段文本变成链接。例如 `tarpaulin’s README.` 中只链接 `README`，不包含 `’s` 和句号。只有跨行大矩形时，再结合原始逐字颜色收紧范围（合并后的 span 会丢失颜色变化），并优先保留被它覆盖的小矩形链接；不能可靠确定边界的同色跨行大矩形保守显示为普通文字，不猜测链接词。
- 依据原始字体粗细、正文字号与行距纠正误判的标题／加粗；同一原始行的正文碎片，以及被伪标题打断、间距连续的正文可以重新接合。保留真实标题、真实段落间隔、独立代码、图片、列表和不同栏，不把所有相邻段落无条件合并。
- 结合固定宽度字体标记、常见代码字体名（兼容缺少 FixedPitch 的 FiraCode）和原始行几何区分行内代码与独立代码块。代码跳过注音；独立代码块恢复行分隔与缩进，复用 EPUB 的原生代码视图及现有语法着色。代码页面再按原始字形坐标恢复阅读顺序：移回被转换器丢到页尾的右侧片段，把同一行的不同字体片段重组为一行，连续代码中的空白行留在同一代码块内；页眉和正文不能夹在 listing 中间。混合字号的章节号／标题／行内类型名按同一物理行恢复，普通正文的软换行重新接合，首行缩进及实际段落间距保留。不会无条件合并相邻代码，也不会猜测删除原有连字符。
- 空列表不再阻止整页代码修复；真实列表保留原始 HTML 和坐标，仅严格确认的外缘同行斜体页眉列表才拆回页眉，保留文字而非删除。编译器诊断行在明确等宽诊断上下文中重组行号、`|`／`||` 与右侧内容，普通多栏仍保守保留。独立源文件注释（例如 `//! tests/health_check.rs`、`#! Cargo.toml`）阻断 listing 合并；不能仅因两段代码间只有空行就把不同文件合成一块。
- 重排位置使用 `extract_chars` 的原始 origin／advance 核对，不能直接信任合并 span 的 `char_x_offsets`：后者可能在合并词语后错移字母，即便新旧字集双射也会把单词重新交错。保留细小脚注标号与随后行内代码之间的间隔。
- 提取嵌入式位图，在正文中按原始位置插入图片并保留图片说明；支持既有图片查看器、主题适配及实测分页。不是把整张 PDF 页变成图片。

- 矢量连线密集且大量标签旋转的图形（如 Attention 第 13–15 页）仅将图形区域和图内标签作为图片恢复。**标题、Figure 图注、正文及页码保留文本**，可随字号重排、注音、选词和高亮；即使与图内标签混在同一旧块，也只投影标签范围。图外公式继续用 Typst。图形按视口缩放，原生点击只放大图形本身；不是整页截图。与正文交叠、字形映射不唯一、裁切会切断墨迹、不支持的坐标变换或超预算时保守回退文本。
- 图形投影保留旧块和全部 UTF-8 文字，不增加提取器／迁移版本或写回快照，也不重排旧快照中已有的行序；旧位置若落在不可见图中标签，原生显示其所属图形。图内不叠加词汇注音；复制仍是原提取顺序，不承诺与图片逐字定位一致。与普通 Typst 公式共用缓存，隐藏标签不产生额外空白阅读页。

## 翻页性能与解析会话

- 桌面端和 Web 端在阅读会话内复用同一个 `PdfDocument`，保留嵌入字体、ToUnicode CMap 和逐字几何缓存；不能在每个 PDF 原始页／内部章节创建新文档。否则即使正文快照已存在，纯正文页也可能为显示投影反复解析整套字体。
- 文档解析会话与六页／8 MiB 的公式／图形投影缓存分开管理，淘汰一张页面投影不清空字体缓存。桌面会话随打开的书籍释放，仍在后台准备目的页；Web 最多保留两份文档解析会话，删除书籍时一并释放。文档打开失败在该会话内记忆，避免后台分页反复尝试；重新打开书籍／重新创建解析会话后重试。
- 纯正文无数学字形时走与完整几何流程等价的空投影快速路径；图形识别先检查旋转标签证据，再提取矢量路径。不能为了提速禁用公式／图形或更改冻结正文。
- 桌面只后台预热相邻前后原始页，最多一个编译在途，前台跳转优先；仍保持六页／8 MiB 投影预算。预热完成不重载可见正文或使当前排版失效，非空投影对应的全书分页版本到实际显示该章时才更新。
- 桌面 PNG 排版测量只扫描有界 chunk header 并 seek 跳过压缩像素，使用与可见图片相同的尺寸限制；动画 atlas、EXIF 旋转和异常图片走原加载路径。PDF worker 提前准备正文静态图，独立 CPU LRU 最多 32 MiB／24 项，键包含文件版本与纸墨色；不能缓存的超预算位图不投机解码。原文件、图示调色算法和原图查看器不变，不先显示占位图再替换造成重排。
- 上述投影／图片阶段的节省不等于完整翻页耗时：原生仍有未预热跨页、分页／动作交付及固定过渡成本，Web 跨章仍是完整导航；同书 EPUB 的章内翻屏仍可能更顺。性能对照和回归边界见 `docs/DEVLOG.md` 的 2026-10-27 记录。
- 首次打开大 PDF 仍有快照校验、文档初始化和字体加载成本；服务重启或解析会话被淘汰后也需重新初始化，不承诺首屏无等待。Web 仍先准备完整投影再返回正文，不采用先显示扁平公式、再异步替换并导致重排的做法。
- 桌面普通运行只输出 PDF 库的 Warn／Error，保留故障信息，不逐字体输出 Info 诊断。这只是减少日志开销，翻页修复依赖解析缓存复用，不是单纯隐藏日志。
- 可只读运行 `cargo run -p readwise-math --example pdf_turn_profile -- /path/book.pdf 10 11 12 13 14 11` 对比逐页重开与会话复用（参数为从零开始的原始页号；正式性能可加 `--release`）。该探针用提取的源文字测试投影阶段，不代表完整 UI 帧耗时，不修改 PDF、数据库或文本快照。

## 原始页与阅读页

每张 **PDF 原始页** 对应一个稳定的内部章节，包括混合文档中的空白／无文本页。重排后的一个原始页可能占用多个阅读页，因此页脚显示的是与 EPUB 一样的**实测阅读页码**，不再把 PDF 原始页数伪装成重排后的总页数。

之前由图片版阅读器导入的 PDF 无需重新入库：首次打开时从原文件提取文本，保留书籍 ID、原始页序、阅读进度和书签。旧的整页位置会落在对应原始页的文本开头，之后保存正常文本锚点。

高亮、笔记、书签仍保存在 ReadWise 数据库中，**不会写回为 PDF 文件内的原生批注**。

## 文本快照与标注稳定性

- 导入时在应用私有 `books/<id>/` 中生成 `pdf-text-v1.json`，保存未注音的语义 HTML、目录、提取器版本和原 PDF 的 SHA-256 指纹。历史图片版 PDF 在首次打开时生成。
- 重开使用同一文本快照，而非每次重新提取；注音投影与“已认识”操作不会修改快照。高亮的块编号和 UTF-8 偏移因此保持稳定。
- 更新提取库版本不会自动替换已有快照。快照损坏或原 PDF 被替换时明确报错，避免静默重建后把标注套到错误的文字上；这时请重新导入为新书，保留旧书以便查看既有数据。
- 文本快照是标注坐标的依据，**不要把它当作可随意删除的图片缓存**。旧版 `.pdf-pages-v1` 图片缓存不再使用，可以删除。
- 标题逐词拆段修复（`semantic-v2`）：新导入按 PDF 原始行的坐标、字号和水平间距重组标题，保留“Chapter 1”和“Getting Started”两条独立标题，不因相同标题标签而合并不同原文行或不同栏。
- 旧 `semantic-v1` 书籍重新打开时，由 `Db::load_book_chapters` 生成独立的 `pdf-headings-v2.json`，**不覆盖原快照**。逐块验证原文字节与新标题内的偏移后，在同一个数据库事务中迁移高亮、书签和阅读位置，并保存一次性迁移标记；失败整体回滚，重开不重复迁移。原 PDF、笔记内容和书籍 ID 保留，无需删除或重新导入。大型书籍首次修复可能需要多几秒，在后台执行；后续复用修复快照。
- 修复后的书籍仍需要原始快照和数据库标记作为坐标依据。原快照丢失时明确报错，不静默重新提取；仅修复投影丢失时，可从原快照生成相同投影并核对已提交标记，不能改变已有标注坐标。
- 代码／链接／图片修复（`semantic-v3`）：新导入直接保存新版正文；旧书从当前有效坐标系生成独立 `pdf-content-v3.json`，不覆盖原快照或标题投影。代码空白只作插入，逐字验证 UTF-8 映射；图片插入后的块编号、高亮起止、书签和阅读位置在同一事务中迁移，结束位置以前一个源字符的结尾为准，避免额外选中下一行的缩进。提交失败回滚，重试／重开不重复迁移。标题已修复的书从标题投影迁移，而不是重新套用原始块编号。
- 链接范围与正文结构修复（`semantic-v4`）：新导入直接使用新版正文；旧书在当前有效 v3 坐标系上生成独立 `pdf-structure-v4.json`，不覆盖原始快照、标题投影或内容投影。仅改变样式、合并完整正文块并在必要时插入空白，逐块校验原字节与 UTF-8 偏移，事务迁移高亮、书签和阅读锚点；旧版像素锚点遇到仅样式变化也改用文本锚点。保留旧投影的序列化 token，重开不重复迁移，投影同值再生、篡改拒绝及失败回滚继续有效。
- 符号字体列表修复（`semantic-v5`）：根据 PDF 原始字体与行几何，将确认属于 Wingdings2 的 U+F0A1 列表符号转换成标准 `•`，并恢复同段列表项之间的换行；未知私用字符、行内符号示例及独立代码不作猜测替换。旧书生成独立 `pdf-lists-v5.json`，保留全部原始／旧版投影。替换前后符号都是 3 个 UTF-8 字节，现有 ASCII 分隔符对应一个换行字节，正文块编号和所有实际文字偏移保持不变；改变排版的旧像素位置转成文本锚点。事务校验只允许这些符号及紧邻分隔符变化，重开幂等、丢失投影同值再生、内容篡改拒绝与失败回滚继续有效。高亮注入与复制统一计入换行字节，避免第二个列表项以后的选区错位。
- 印刷目录修复（`semantic-v6`）：目录页眉结合多个编号条目确认页面类型，再从原始逐字坐标恢复行序，保留粗体／斜体／行内代码。旧书在当前有效 v5 坐标系上生成独立 `pdf-toc-v6.json`，保留原 PDF、原始文本及全部历史投影；逐字校验新旧非空白字符一一对应。高亮按原选中字集迁移，书签及位置按字形落点迁移，排版变化的像素位置改用文本锚点；若重排后连续高亮会夹入未选文字则拒绝并回滚，原标注保持不变。保留事务标记、重开幂等、丢失投影同值再生和篡改拒绝。不能可靠对应字形的页面继续使用原排版。
- 代码／正文几何重排（`semantic-v7`）：旧书在当前有效 v6 坐标系上生成独立 `pdf-reflow-v7.json`，不修改原 PDF、原始快照或 v2–v6 投影。先把全部旧文本映射到未使用的原始字形，再按行坐标恢复顺序和分组，保留粗斜体、链接、行内代码、代码空白及正文词间空格。一个旧块可以分散到多个新块，因此保存逐 UTF-8 字节的「新块＋字节」落点，不再假定每个旧段只有一个目标块。逐字验证所有非空白字符的双射；高亮仍按原选中字集迁移，不能夹入未选文字，范围落在 UTF-8 字符内部也拒绝。高亮／笔记、书签、阅读锚点及一次性标记事务提交，失败回滚、重开幂等、投影同值再生及篡改拒绝继续有效。图片／列表／显式换行／表格页面沿用专门投影；疑似多栏或不能完整对应的页面保留原排版，不猜测跨栏顺序。
- 列表混合代码／诊断栏与原始字符坐标修复（`semantic-v8`）：新导入使用 v8；旧书先完成原有 v7 迁移，再在已提交的 v7 坐标系上生成独立 `pdf-reflow-v8.json`，原生 v7 导入也能接续。**v7 算法、原始快照及 v2–v7 投影不重写**，不能把新算法塞回旧版本。v8 继续逐 UTF-8 字节保存跨块落点，验证完整非空白字符双射和安全高亮范围；真实列表作为不透明块保留原始字节。无变化／无法可靠修复的页面使用精确 identity HTML／映射，不混入旧偏移格式。标注、书签、位置及 `pdf_reflow_projection_v8` 标记事务提交，保留失败回滚、重开幂等、投影同值再生及篡改拒绝。已有 v8 同样必须冻结，后续算法变化另起版本。
- 图片派生文件保存在私有 `pdf-assets-v3/`，快照只记录相对路径，可随应用数据目录一起迁移。派生图片丢失时可以从 PDF 原件恢复，**不重新提取正文**；文本快照与迁移标记仍不可随意删除。单张图片超过 32M 像素时明确拒绝解码，避免无界内存分配。
- 首次内容修复在后台进行，大型 PDF 可能需要数十秒或更久；之后复用投影及图片。任意外部源的只读 `load_pages()` 不在用户文件旁创建图片或缓存；完整图片提取使用入库后的私有副本。
- 本机选择器／拖放的用户原文件旁边不会创建快照或临时文件。删除书籍只移除应用自己的副本、快照、进度及笔记，不删除用户原文件。`import` 投递目录仍遵循既有规则：成功入库后移除投递文件。

## 当前边界

- 这是**文本重排阅读**，不保留 PDF 原版式、精确坐标及颜色；标题、段落、粗斜体、列表、表格及阅读顺序由 pdf_oxide 推断，再经过现有正文清洗。复杂多栏、公式、特殊字体或编码异常仍可能影响提取质量。
- 嵌入位图与保守确认的矢量图主导页可显示；不是任意插图、表格或复杂混合图文区域的通用恢复方案，未命中的矢量图仍可能只有说明文字。公式另由共享 Typst 几何投影恢复，详见 [Web／原生公式实现](WEB.md#pdf-公式与-typst)。位图内的文字不做 OCR，不能直接选词／注音。没有文本层的纯扫描件仍会提示先做 OCR；混合文档保留无文本页的原始索引，可以展示其中的嵌入图片。
- PDF 连字会归一化，例如 `ofﬁce` 转为 `office`，以便查询和注音；原 PDF 不变。
- 暂不提供密码输入。需要密码的文档会提示先解密，不会以空文本假装成功。
- 手机真机的文件选择、手势及后台传书需单独验收，桌面模拟和交叉编译不等同于真机验证。

## 实现入口

- `core/src/books/pdf.rs`：pdf_oxide 元数据、语义 HTML、大纲及私有文本快照。
- `core/src/books/pdf/headings.rs`：按原始行几何修复标题，生成块编号与 UTF-8 偏移映射；不改 EPUB。
- `core/src/books/pdf/content.rs`：逐字链接边界、行内／独立代码识别、代码空白映射、嵌入位图及派生资源恢复。
- `core/src/books/pdf/structure.rs`：逐字颜色收紧跨行链接，校正正文的伪标题／粗体与错误段落边界，保留原文字节。
- `core/src/books/pdf/lists.rs`：按符号字体及原始行位置确认列表标记，恢复标准项目符号与换行，保留正文偏移。
- `core/src/books/pdf/toc.rs`：正文重排前识别印刷目录，按逐字几何恢复行序和页码，生成允许重排的精确源偏移映射。
- `core/src/books/pdf/reflow.rs`：从未重复使用的原始字形恢复代码／正文的行序、连续 listing、代码缩进／空行与混合字号标题，生成允许跨目标块的逐字落点。
- `core/src/books/pdf/reflow_migration.rs`：冻结的 v7 独立投影持久化与旧坐标系逐字验证，复用原有事务迁移。
- `core/src/books/pdf/reflow_v8.rs`：混合列表／代码页、严格页眉列表例外、编译器诊断 gutter、不同源文件边界及原始字符 origin／advance 核对。
- `core/src/books/pdf/reflow_v8_migration.rs`：从 v7 坐标接续的独立 v8 投影、逐字验证与事务迁移，兼容原生 v7 导入。
- `core/src/books/pdf/migration.rs`、`core/src/db.rs`：持久化书籍的安全加载，旧 PDF 坐标迁移、快照校验及幂等提交。
- `core/src/books/mod.rs`：格式分流；任意源文件的只读提取与应用私有书籍的快照加载分开。
- `core/src/books/queries.rs`：复制后提取并保存快照，全部成功才提交入库；失败回滚私有目录。
- `math/src/figures.rs`：矢量图主导页的保守识别、受限原图渲染与不改源块的投影。
- `app/src/reader_math.rs`：原生 Typst SVG／PDF 图形纹理及图形源代理；`web/src/style.css` 提供对应 Web 显示。
- `app/src/app.rs`：后台加载后复用 EPUB 的 `OpenBook`、Html／RubyWord、选区、高亮、搜索、图片查看器和实测分页，不使用 PDF 原始页数代替阅读页码。
